# ДЗ 2. Задача 3: Символьне виведення рівнянь маятника

## Мета

Символьно отримати рівняння руху оберненого маятника, розв'язати їх відносно `x_ddot` і `phi_ddot`, лінеаризувати біля верхнього положення та порівняти матриці з CTMS.

## Реалізація

Скрипт `symbolic_pendulum/run_symbolic_pendulum.m` викликає `derive_pendulum_model.m`. Він має:

1. Створити символьні змінні параметрів і станів.
2. Записати два нелінійні рівняння руху.
3. Використати `solve` для знаходження `x_ddot` та `phi_ddot`.
4. Лінеаризувати модель біля `phi = 0`.
5. Утворити матриці `A` і `B` через `jacobian`.
6. Чисельно підставити параметри CTMS і перевірити збіг.
