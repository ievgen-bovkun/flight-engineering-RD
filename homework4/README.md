# ДЗ 4 — лінеаризація поздовжнього руху ЛА, варіант 1

Ця папка містить відтворювану технічну частину ДЗ 4. Вона реалізує
систему зі сталими швидкістю й тягою (система (7) методичних вказівок),
обчислює коефіцієнти `Qij`, складає матриці `A`, `B`, створює Simulink-модель
і порівнює її відповідь з незалежним MATLAB-розрахунком `lsim`.

## Швидкий запуск

У MATLAB виконайте:

```matlab
run('C:\\Users\\ievge\\Documents\\Flight Engineering\\homework4\\scripts\\run_dz4_variant1.m')
```

Сценарій заново збереже модель, запустить стрибок керуючого органу і
оновить усі файли у `results`.

## Вміст

- `source_from_colleague/DZ_4_colleague.m` — початковий файл колеги,
  збережений без зміни.
- `scripts/` — відтворювані розрахунки, побудова Simulink-моделі та експорт.
- `models/dz4_longitudinal_ss.slx` — згенерована модель
  `Step → State-Space → Demux → Scope`.
- `tests/` — автоматичні тести вхідних даних, матриць, схеми, чисельної
  відповідності та експорту.
- `results/` — числові результати, графіки та знімок схеми для звіту.
- `report/` — PDF-звіт та скрипт його відтворюваної побудови.

## Варіант і вхідні дані

Виконано **варіант 1**:

- нормальна аеродинамічна схема;
- `m = 44 кг`, `I_z = 13.46 кг·м²`, `V = 476 м/с`;
- кутовий стрибок керма: `δ₁ = −4°` у момент `t = 1 с`;
- похідні з таблиці перетворюються з `1/град` у `1/рад` множенням на
  `180/pi`.

Для нормальної схеми знак керуючого впливу задано від’ємним; це важливо
для фізичної інтерпретації реакції.

## Контроль виконання

Автоматична перевірка підтверджує:

1. правильність перетворення одиниць і знаку для варіанта 1;
2. відповідність матриць `A` і `B` методичній формі (34);
3. наявність блоків Step, State-Space та To Workspace у моделі;
4. збіг MATLAB `lsim` і Simulink з максимальною похибкою менше `1e-5`;
5. наявність початкової від’ємної просадки висоти;
6. створення графіків та PNG-схеми.
