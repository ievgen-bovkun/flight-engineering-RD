# Курсовий проєкт: керування двигуном постійного струму

Три реалізації MATLAB/Simulink: диференціальні рівняння, простір станів та
фізична підсистема Simscape. Незалежна модель Python, оптимізований ПІД,
lag/lead, збурення та справжні FMU MATLAB порівнюються чисельно через CLI.
Фінальний звіт українською; таблиці й графіки формуються з CSV/JSON.

## Потрібне середовище

- Windows x64; MATLAB R2026a Update 4.
- MATLAB, Simulink, Control System Toolbox, Simscape, Simscape Electrical
  із чинними ліцензіями (ці продукти є у перевіреній пробній ліцензії).
- Python 3.12 (перевірено 3.12.14) та залежності з `requirements.txt` (зафіксовані перевірені версії).

**FMU використовують офіційний tool-coupling, а не автономний експорт.**
Для їх виконання потрібні локальні ліцензовані MATLAB і Simulink R2026a.
Додаткова ліцензія Simulink FMU Builder та C/C++ компілятор не потрібні.
FMU не працюватимуть на комп'ютері лише з Python або MATLAB Runtime.
Після завершення trial для повторного виконання потрібна чинна ліцензія.
Підхід tool-coupling виконує експорт і порівняння FMU з Python у межах наявної пробної ліцензії; автономний експорт через FMU Builder у ній недоступний.

## Запуск із репозиторію

У PowerShell, з кореня репозиторію:

```powershell
python -m venv coursework/dc_motor/.venv
& './coursework/dc_motor/.venv/Scripts/python.exe' -m pip install -r coursework/dc_motor/requirements.txt
& './coursework/dc_motor/scripts/run_all.ps1' -Mode Full
```

`Full` виконує MATLAB-тести, регенерує моделі/траєкторії, експортує два
FMU, порівнює їх через FMPy на двох сітках, виконує Python-тести, повторює
обчислення з чистої копії, складає фінальний PDF та ZIP і перевіряє архів.
Кожна помилка припиняє запуск; обов'язкові перевірки не пропускаються.
Окрема службова MATLAB-сесія створюється й закривається автоматично.
Ручні натискання у MATLAB/Simulink не потрібні. Запуск триває кілька хвилин.

Для іншого MATLAB/Python використайте `-MatlabExe` та `-PythonExe`.
Для нового повного пошуку коефіцієнтів додайте `-RegenerateOptimization`;
звичайний запуск перевіряє походження збереженого результату оптимізації
та повторно обчислює відгуки. Змінений код/конфігурація відхиляють застарілі
коефіцієнти. Параметр `-ComputeOnly` є внутрішнім режимом перевірки копії:
він не оголошує фінальне подання готовим і не створює фінального архіву.

## Запуск із ZIP

Розпакуйте архів. Він містить каталог `dc_motor`. Розмістіть його як
`coursework/dc_motor` у будь-якому порожньому каталозі й виконайте команди
вище. `SHA256SUMS.json` містить контрольні суми всіх файлів архіву.

Швидка перевірка цілісності ZIP:

```powershell
& './coursework/dc_motor/.venv/Scripts/python.exe' coursework/dc_motor/scripts/package_submission.py --verify coursework/dc_motor/delivery/DC_Motor_Coursework.zip
```

Повторне складання PDF із перевірених результатів:

```powershell
& './coursework/dc_motor/.venv/Scripts/python.exe' coursework/dc_motor/report/build_report.py
```

Режим `Core` виконує математичні та фізичні перевірки й створює окремий
проміжний PDF. Фінальний режим звіту відхиляє неповні, змінені чи відсутні
FMU-результати та доказ відтворення з чистої копії.

## Модель, припущення та результати

Ra=2 Ом, La=0.5 Гн, Kt=Ke=0.1, Jm=0.01 кг·м², Bm=0.001 Н·м·с/рад,
JL=0.02 кг·м²; J=0.03 кг·м². Стан: `[i; omega]`, позитивний зовнішній
момент протидіє обертанню. Передавальна функція:

`G(s)=0.1/(0.015*s^2+0.0605*s+0.012)`.

Напруга ±48 В, перерегулювання ≤5% і похибка ≤0.2 рад/с є явно обраними
інженерними припущеннями. Викладач задав 100 рад/с протягом 2 с і
мінімізацію похибки/керуючого впливу. Час усталення оцінюється як останній
вихід за межі ±2% плюс наступний відлік, а не перше входження у смугу.

Оптимізований ПІД: Kp=17.95945476, Ki=45.04480104, Kd=1.84809831.
Номінально: ts=1.675 с, OS=0.163%, IAE=89.805 рад, ∫|V|dt=109.847 В·с.
Фізичний ПІД із моментом 0.05 Н·м при t=1 с: ts=1.690 с.
Зменшення IAE порівняно з розміщенням полюсів супроводжується невеликим
збільшенням витрат напруги. Lag перевищує 2 с; lead має похибку 1.525 рад/с.
Ці обмеження наведено у звіті; універсальна перевага не заявляється.

FMU: нульові початкові стани, ode4 із кроком 0.00001 с; обмін 0.001 та
0.0005 с; новий FMI-екземпляр на сценарій. Входи двигуна `[Vin, TL]`,
виходи `[omega, i]`; ПІД: входи `[omega_ref, TL]`, виходи `[omega, i, Vin]`.
Метадані, одиниці, CRC, SHA256 і чисельні похибки перевіряються перед поданням.

## Файли та походження

- `config/`: фізичні параметри, припущення й сценарії.
- `matlab/`: вихідний код, тести, десять згенерованих SLX.
- `python/`: незалежна модель, метрики, FMPy та тести.
- `fmu/`: два справжні FMU, експортовані MATLAB.
- `results/`: виміряні CSV/JSON, графіки та SHA256-маніфест.
- `report/DC_Motor_Coursework_UA.pdf`: фінальний український звіт.
- `delivery/DC_Motor_Coursework.zip`: комплект здачі з контрольними сумами.

Оригінальні 30 файлів колеги збережено незмінними у `reference/buddy/src`.
Походження та SHA256: `reference/source_manifest.json`; технічний огляд
і виправлення F1–F6: `reference/buddy_review.md`. Автори попередніх спільних
навчальних матеріалів: Dmytro Povolotskyi та Ievgen Bovkun.

Довідкові матеріали: [CTMS](https://ctms.engin.umich.edu/CTMS/index.php?example=MotorSpeed&section=SimulinkSimscape)
та [офіційний tool-coupling FMU](https://www.mathworks.com/help/simulink/ug/export-model-as-tool-coupling-fmu.html).
